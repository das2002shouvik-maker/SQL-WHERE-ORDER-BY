# SQL WHERE and ORDER BY Practice

## About the Project
This repository contains SQL practice questions and solutions focused on filtering records and sorting query results. It is designed to strengthen SQL fundamentals through hands-on exercises.

## Topics Covered
- WHERE clause
- Comparison operators: `=`, `<>`, `>`, `<`, `>=`, `<=`
- Logical operators: `AND`, `OR`, `NOT`
- `IN` and `BETWEEN`
- Pattern matching using `LIKE`
- ORDER BY with `ASC` and `DESC`

## Repository Structure
- `where_clause.sql` — Filtering practice questions and solutions
- `order_by_clause.sql` — Sorting practice questions and solutions
- `sample_table.sql` — Optional table creation and sample data

## Tools Used
- SQL
- MySQL Workbench

## Objective
To improve SQL query-writing skills and build a strong foundation for data analytics, database management, and technical interviews.

## Learning Outcome
Practiced filtering employee records, applying multiple conditions, matching values against lists, and sorting query results using multiple columns.
